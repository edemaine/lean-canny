Acceptance target

For original joint packet u, bounded zero-count index K, and two prescribed
old candidate labels a,b, construct a polynomial-space bounded checker such
that its accepted words exist iff the actual joint stratum has a real point
whose two closed-source projections belong to the components named by a,b.
Both directions must use the SAME decoded point. No caller-supplied JoinedIn,
component association, native evaluator, complete square system or expanded
product Term is an acceptable missing implementation.

1. Actual implicit equation

Use the existing JointCoefficientCatalogue, with its actual integer features
f_i and binary count M. Put P(T,x)=product_{i<M}(T+f_i(x)^2).
Let C(x) be the literal joint Core polynomial, U_K=[T^K]P, and L_K=0 for K=0,
otherwise [T^(K-1)]P. Add ONE last variable z and define

  Q(x,z)=C(x)^2+L_K(x)^2+(U_K(x)*z^2-1)^2.

Q=0 enforces the actual Core and exactly K zero features. All x columns stay
literal. No product Term is serialized. If feature degree/mass charges are
d,h, set dP=M*(2*d+1), hP=M*(2*h+1). A safe degree charge is
D=max(2*dC,2*dP+4), and a safe mass exponent is H=2*max(hC,hP)+4.
Dimension m=jointDimension+1 is unary; D,H,M,K are binary. Modular coefficients
come from a fixed number of renames, sums and convolutions of the Core and
the already constructed product-coefficient Source. Loops enumerate exponent
splits with polynomial-length counters; coefficient integers are not emitted.

2. Finite grid instead of an expanded critical sampler

For each coordinate i, use the actual CoerciveBoxGramEliminant G_i(epsilon,T)
of Q. This is a fixed padded block determinant, with no chosen maximal minor
or universal-resultant quotient. Existing theorems prove G_i nonzero and
G_i(epsilon,x_i)=0 at actual coercive critical points.

Let W be the binary size of the maximum of the homogeneous degree and
Macaulay level, N=2^((m+1)*W), and L=(m+3)*N. Both parameter degrees of G_i
are bounded by L. The block determinant has binary degree/mass charges and
PSPACE coefficient access from the actual homogeneous Q rows.

A short table Gamma stores (tau_i,r_i), each at most L. Set p_i=[epsilon^tau_i]G_i
and let h_i=p_i when its r_i coefficient is nonzero, otherwise h_i=1.
Nonzeroness is internal on EVERY table: one witnessed nonzero coefficient,
or the constant-one fallback. Its test uses modular coefficient access and
an integer-zero program, not an exponentially long exact coefficient.
The encoded Gamma length is at most (6*size(L+1)+6)*m. True trailing tau_i and suitable r_i exist
by G_i nonzeroness. Soundness does not require Gamma to be trailing.

Build diagonal rows h_i(X_i), with annihilators h_i. Completeness is then a
direct row-evaluation identity; repeated roots use the existing squarefree
grid machinery. Decode an OWN exact-width complete-sampler word and test
Q=0 at that SAME tuple using the native polynomial-sign test. Arbitrary grid
points are not assumed to satisfy Q.

Component hit uses ONE actual critical-limit vector in the original stratum
component. All G_i pass to their true trailing coefficients at that same
limit. The resulting grid point still satisfies Q, remains in that component,
and has an exact OWN word. CoerciveGramComponentGrid formalizes this geometric
step. Native Gram access, the actual equation Source and the word/filter
assembly are separate implementation steps; that geometric file is not the
completed sampler.

The existing two-prefix geometry can then compare OLD and EXTERNAL through

4. Essential distinction: containment and joining radius

This construction first gives Assoc_R: membership in the same component
INSIDE the chosen ball. Head height/degree root bounds and the old candidate
bound give endpoint containment. They do not bound a joining path.
The old closed-circular source can be unbounded; proper projection does not
make its entire zero set bounded.

EffectivePolynomialBallConnections now proves the needed geometric contract
directly. For an integer polynomial q with degree at most D and coefficient
mass at most 2^H, a cutoff radiusExponent(n,D,H) has BinaryFn controls.
For every R above that cutoff and every pair of endpoints already in the
literal bounded zero set, JoinedIn and connectedComponentIn agree with the
entire original zero set. Singular and unbounded zero sets are covered.
No regularity, parameter head, exclusion interval or stabilization oracle
is an input. Actual boundary Gram heads derive a small-residual critical
band exclusion; proper two-circle transport and compact residual limits
then identify the bounded and original connections.

Consequently a correct bounded two-provider association checker at this
common radius will also decide unbounded component association. It need not
first transport every record word as R varies. The bounded checker and its
correctness remain necessary; the geometric theorem does not supply them.
